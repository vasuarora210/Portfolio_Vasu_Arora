05 HOW I WORK

I don't start with the dashboard. I start with the question.

A repeatable workflow keeps the analysis grounded in the actual business problem instead of turning the dashboard into decoration.

→ → → → → →
QUESTION

Define what the business actually needs to know before touching the data.

RAW DATA

Understand the source, structure, gaps, and what "correct" should look like.

CLEAN

Handle missing values, duplicates, inconsistencies, and data quality issues.

TRANSFORM

Join, reshape, aggregate, and prepare the data for analysis.

ANALYZE

Use SQL and Python to identify patterns, relationships, and anomalies.

VISUALIZE

Turn analysis into dashboards and visuals that make the finding easy to understand.

INSIGHT

Explain what changed, why it matters, and what action it suggests.
